# Chợ Nhà Smart Food (Web)

Bản web bán hàng, giao diện và luồng nghiệp vụ bám theo ứng dụng WinForms **Chợ Nhà Smart Food**.

## Mở website

Cách 1 — mở trực tiếp:

- Nhấn đúp `index.html`

Cách 2 — Live Server / trình duyệt:

```powershell
cd "D:\ĐỒ ÁN CƠ SỞ NGHÀNH"
python -m http.server 5500
```

Rồi vào `http://localhost:5500`

## Tài khoản demo (giống Visual Studio)

| Vai trò | Tài khoản | Mật khẩu |
|---------|-----------|----------|
| Khách hàng | `customer` | `Customer@123` |

## Chức năng khách hàng

Trang chủ, sản phẩm, chi tiết, giỏ hàng, thanh toán, trợ lý AI, đơn hàng, tài khoản, đánh giá, vòng quay voucher.

## Chức năng admin / nhân viên

Tổng quan, sản phẩm, đơn hàng, khách hàng, đánh giá, voucher. Admin thêm: danh mục, quản lý AI, báo cáo.
